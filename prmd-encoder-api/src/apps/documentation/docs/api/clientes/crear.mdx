# Creador

## Introducción
Método api rest para crear de códigos de **clientes**.

### Ejemplo de código
ALFA3 país + código de tipología de cliente + código tamaño cliente + secuencial
`customerCode:` `PAN-120-2-C123456`

### Ruta
Para crear un código hay que hacer una petición ```PUT``` **a la siguiente ruta**.
```/customers-encoder```

<br /><br />

## Contenido de la petición
Para que la petición funcione hay que pasarle por el body los siguientes **parametros en formato JSON**.

```json
{
    "name": "Clinica Example S.L",
    "isGroup": false,
    "typeOfTaxIdentifier": "NIT",
    "taxIdentifier": "B76365789",
    "country": "spain",
    "typology": 140,
    "size": 2
}
```

## Respuesta

### Ejemplo de respuesta correcta
La respuesta sera devuelta con un código `200`
```json
{
    "id": "3e71220c-b931-4509-8a25-519f949f3e06",
    "customerCode": "PAN-120-2-C123456"
}
```
`id:` Identificador de la codificación

`customerCode:` Código del cliente


### Ejemplo de respuesta incorrecta

La respuesta sera devuelta con un código `400`
```json
{
    "message": "Mensaje de error"
}
```
`message:` Mensaje de error
